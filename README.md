# Global Expo · Ad Platform

Рекламная платформа [Global Expo](https://global-expo.uz) — организатора
международных выставок в Ташкенте. Функционально это та же платформа, что
и Setanta Sports Platform (кампании, договоры и оплаты, рекламодатели,
пользователи, отчёты), но с полностью своим визуальным языком.

## Дизайн: «Павильон»

|                  | Setanta Sports Platform            | Global Expo                                                                    |
| ---------------- | ---------------------------------- | ------------------------------------------------------------------------------ |
| Навигация        | боковое меню                       | тёмная верхняя «вывеска», разделы с номерами 01, 02…                           |
| Цвет             | фирменный жёлтый на тёплом светлом | изумрудный Global Expo (`#0E7745`) + мятный сигнальный, тёмно-зелёный `forest` |
| Форма            | крупные скругления, «пилюли»       | прямые углы, прямоугольные таблички                                            |
| Глубина          | мягкие тени, стекло                | тонкие линии, чертёжная сетка, без размытия                                    |
| Шрифты           | Setantica + Noto Sans              | Montserrat (заголовки) + Manrope (текст) + JetBrains Mono (подписи)            |
| Формы и карточки | модальное окно по центру           | боковая панель справа во всю высоту                                            |
| Вкладки          | сегменты-«пилюли»                  | вкладки-указатели с планкой снизу                                              |
| Графики          | плавные кривые, круглые точки      | ломаные линии, квадратные маркеры                                              |
| Вход             | ТВ-витрина с роликом               | план выставочного павильона с выставками компании                              |

Тема живёт в блоке `@theme` в [src/index.css](src/index.css). Имена токенов
остались прежними (`paper`, `ink`, `indigo-*`, `lime-*`), чтобы экраны не
переписывать: `indigo-*` здесь — фирменная зелёная шкала, `lime-*` — мятная,
`forest` — тёмная «вывеска». Утилиты стиля: `eyebrow` (моноширинная подпись
капсом), `corner-ticks` (уголки-засечки), `bg-grid-fade` / `bg-blueprint`
(чертёжная сетка), `bg-hatch` (штриховка пустых зон).

Эмблема — [public/brand/global-expo-emblem.png](public/brand/global-expo-emblem.png)
(с сайта компании, 142×142). Для крупных размеров лучше получить у Global Expo
векторный логотип.

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5188` (Setanta занимает 5178 — оба проекта
можно держать запущенными одновременно).

## Данные: демо-режим

По умолчанию платформа работает **без API**: на все запросы отвечает
«бэкенд в браузере» из [src/mock](src/mock) — те же маршруты и формы ответов,
что у настоящего сервера, поэтому экраны и хуки запросов об этом не знают.
Подменена только точка выхода в сеть — `send` в [src/api/client.ts](src/api/client.ts).

- Демо-данные — [src/mock/seed.js](src/mock/seed.js): 5 брендов, 6 договоров,
  6 кампаний, 5 пользователей, отчёты по двум договорам (по 6 строк на лист).
- Правки сохраняются в `localStorage` (ключ `globalexpo.mock.v2`) и переживают
  перезагрузку. Вернуть исходные данные — удалить этот ключ или вызвать
  `resetMockDb()` из `src/mock/server.js`.
- Ролик кампаний — [public/creatives/global-expo-demo.mp4](public/creatives/global-expo-demo.mp4),
  скан договора — `public/contracts/nda-artel.docx`.

### Настоящий API

Схема API та же, что у Setanta. Когда у Global Expo появится свой сервер,
включите его переменной `VITE_USE_API=true`; локальный прокси берёт адрес из
`API_PROXY_TARGET` (см. [.env.example](.env.example)), на Vercel — правило
«API Proxy» в Routing rules проекта.

Скрипты заливки демо-данных из `scripts/` требуют явный `--api`: адреса по
умолчанию у них нет, чтобы данные случайно не ушли на чужой стенд.

## Доступы и роли

Роли те же, что в исходной платформе: `admin`, `viewer`, `advertiser`.

| Раздел            |   admin    |     viewer      |           adv            |
| ----------------- | :--------: | :-------------: | :----------------------: |
| Кампании          | все + CRUD | все, без правки | только свои + CRUD своих |
| Обзор             | все данные |   все данные    |          скрыт           |
| Договоры          |    CRUD    | только просмотр |          скрыт           |
| Рекламодатели     |    CRUD    | только просмотр |          скрыт           |
| Отчёт             |   скрыт    |      скрыт      |     по своему бренду     |

## Что ещё от Setanta

- Состав отчёта (листы Live Spot / Standart Spot / Event Promo, OTT, лиги
  в «Обзоре») повторяет ТВ-шаблон Setanta — названия каналов заменены на
  нейтральные «Канал 1 / Канал 2». Когда станет известен формат отчёта
  Global Expo, листы и подписи нужно будет перестроить под него.
- Документы в [docs/](docs) описывают общую схему API и написаны для Setanta.

## Стек

React 19 · Vite 8 · Tailwind CSS 4 · TanStack Router · TanStack Query ·
Zustand · Framer Motion · lucide-react. Шрифты — `@fontsource-variable/*`,
грузятся из пакета, интернет не нужен.

```bash
npm run lint       # ESLint
npm run format     # Prettier
npm run typecheck  # tsc --noEmit
```

## Структура

```
src/
  api/         — слой запросов: client.ts, endpoints/, типы
  components/
    ui/        — дизайн-система (Button, Card, Modal-панель, Field, Tabs, Toast, …)
    charts/    — SVG-графики (Area, Bar, Donut, Sparkline)
    forms/     — формы CRUD (открываются боковой панелью)
    layout/    — AppShell, Topbar (тёмная шапка), Navigation
  features/    — логика по доменам: auth, advertisers, campaigns, contracts, …
  stores/      — Zustand-сторы (authStore)
  lib/         — store (localStorage), seed, metrics, format, nav, хуки
  pages/       — Login, Campaigns, Dashboard, ContractOverview, Advertisers, …
```
