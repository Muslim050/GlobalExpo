# QA: отчёт за месяц из файла статистики

Раздел: **Кампании → бренд → договор → месяц → «Статистика»**.
Стенд — сборка ветки `dev`.

## Что нужно

- **Учётки:** `admin` / `admin`; `viewer` (пароль — у бэка); рекламодатель —
  `cola` или `artel`.
- **Файл:** «Шаблон импортируемого отчёта Setanta Statistics» — данные за
  **январь 2026**.
- **Битый файл:** любой файл, переименованный в `.xlsx`.
- **Договоры для проверок:** чистые — Test Logo ADV → «Д-2026-TEST» и Artel →
  «Д-test». В Coca Cola → «Doc Dowload test 77» январь уже загружен, там
  удобно проверять замену.

> Отчёт на сервере удалить нельзя, только заменить. Боевые договоры не трогаем.

## Роли

| Роль          | Видит                                                                         | Не должно быть                                             |
| ------------- | ----------------------------------------------------------------------------- | ---------------------------------------------------------- |
| `viewer`      | листы, «Скачать Excel»; в пустом месяце — «Загрузить его может администратор» | зоны загрузки, «Заменить файл», «История», «Редактировать» |
| рекламодатель | только договоры своего бренда, листы, «Скачать Excel»                         | то же, что у viewer; чужих договоров                       |

## Не баги

- **Total, Spot и категория OTT** — демо-данные в браузере, с сервера не приходят.
- **У Live spot нет Pre/Mid/Post, «Просмотров» и строк «Итого»** — этих данных нет в API.
- **Проценты при загрузке — оценка.** Сервер прогресса не отдаёт, до 100 % они не доходят.
- **1 февраля в январском отчёте** — ночной хвост эфиров 31 января, так и должно быть.
